# 确定性答案模块设计说明（2025 年报，第一阶段）

生成日期：2026-10-21

对应代码：`src/answer.py`
对应测试：`tests/test_answer.py`
对应报告：`deliverables/answer_test_2025.json`、`deliverables/answer_test_2025.md`

## 1. 目标与边界

本阶段只实现**基于现有检索结果和确定性规则**的答案模块：

- 不调用大模型 API；
- 不开发 Streamlit；
- 不新增第三方依赖；
- 不修改原始 PDF、解析 JSONL、异常记录、固定测试题或既有检索判定标准；
- 不把检索排名当作答案；
- 不把助手对原始页面的检查当作人工已确认。

模块输出的是**可审计的规则答案**，不是人工核定答案。所有答案的
`人工核验状态` 固定为 `待核验`；10 题答案准确率固定记为 **未评测**。

## 2. 处理流程

```
问题 + 检索结果
  → _scope_codes()        确定合法公司范围，隔离跨公司结果
  → _filter_results()     只保留范围内的检索块
  → _build_pages()        建立页记录；主结果优先于上下文片段
  → _build_rows()         按原文行解析指标、数字、单位、章节、表名
  → _intent()             识别题型（分红/研发/地区/渠道/产品/财务等）
  → 对应 handler          抽取指标并做阻断、表头、冲突、口径检查
  → _base_answer()        统一安全门禁与答案结构
```

关键原则：

1. **先定范围，再抽指标**。单公司题只允许题面识别出的公司代码进入答案；
   全公司题的范围是 `config/companies.csv` 的 14 家公司全集，而不是本次
   检索碰巧召回的子集。
2. **主结果优先**。`_build_pages()` 先放入全部主结果页，再放入上下文片段，
   防止某个上下文页抢占同页主结果、把 `blocked=true` 错误覆盖成未阻断。
3. **证据可追溯**。每条指标保留数据页、表头来源页、表名、原文行和
   `doc_id`；计算值单独写明计算依据。
4. **不猜口径**。指标名不一致时保留原文，不把“海外”自动改写成“境外”，
   不把“营业收入”自动等同于“营业总收入”。

## 3. 统一答案结构

`answer_from_results()` / `answer_question()` 返回字典，主要字段：

| 字段 | 含义 |
|---|---|
| 题目编号 / 问题 | 题目标识与题干原文 |
| 回答状态 | 可回答 / 需口径说明 / 需核验 / 证据冲突 / 证据不足 / 已阻断 |
| 答案正文 | 规则生成的回答或明确拒答 |
| 公司 / 证券代码 / 报告年份 | 单公司题的公司信息；跨公司题为空或列表 |
| 检索范围证券代码 | 本题允许出现的公司代码，用于跨公司混淆检查 |
| 指标 | 逐条证据记录（见下表） |
| 数据页码 / 表头来源页码 | 答案正文所依赖证据的页码汇总 |
| 证据原文 / 口径说明 | 原文行与口径提示 |
| 警告 / 拒答原因 | 风险提示与不能回答的原因 |
| 确定性作答 | 是否允许作为规则结论（`true/false`） |
| 人工核验状态 | 固定为 `待核验` |
| 方法说明 | 固定说明“未调用大模型；未经人工语义核验” |
| 审计 | 题型专属审计信息（Q04/Q07/Q09/Q10 最详细） |

每条 `指标` 记录包含：

```
公司简称、证券代码、报告年份、指标原文、数值、单位、
数据页码、表头来源页码、表名、证据原文、来源类型、口径说明、
blocked、是否采信、上下文关联状态、
reliable_for_deterministic_answer、表头核验状态、计算依据、doc_id
```

## 4. 状态模型与安全门禁

| 状态 | 触发条件 | 确定性作答 |
|---|---|---|
| `可回答` | 指标、单位、年份、公司、页码明确；证据未阻断；无口径/表头/冲突问题 | 是 |
| `需口径说明` | 数值可靠，但指标名或分母存在多种口径，需读者按题面选择 | 是（仅展示原始口径与计算口径） |
| `需核验` | 结论依赖“算法判定，待人工核验”的跨页表头，或表头未找到 | 否 |
| `证据冲突` | 同一报告内两张表对同一指标给出不同数值，原因未明 | 否 |
| `证据不足` | 检索结果缺少题面所需指标，或不允许在口径统一前排名 | 否 |
| `已阻断` | 关键证据页 `blocked=true` 或 `reliable_for_deterministic_answer=false` | 否 |

`_base_answer()` 中有一道统一的**阻断门禁**：

- 若状态本应为 `可回答` / `需口径说明` / `证据冲突`，但任一被引指标
  满足 `blocked=true` 或不可靠，则自动降级为 `已阻断`，`确定性作答=false`；
- 被阻断的指标必须 `是否采信=false`，只能作为候选记录；
- 该门禁同时覆盖手工构造的 Evidence，避免某个 handler 漏标。

跨页表头门禁：

- `表头来源` 为 `上下文` 且 `关联可靠性` 含“待人工核验”，或 `表头来源`
  为 `未找到` 时，`needs_header_verification=true`；
- 依赖该表头的行在 `指标` 中标注 `表头核验状态=待人工核验`，
  `是否采信=false`；
- 只有数据页本身有独立表头（`表头来源=页内已有表头`）时才标 `不适用`。

## 5. 题型分派

当前分派顺序（`answer_from_results()`）：

1. 利润分配 / 分红 → `_answer_dividend`
2. 研发 + 地区（非全公司） → `_answer_overseas_rd_comparison`
3. 全公司 + 地区 → `_answer_overseas_ranking`
4. 单公司地区 → `_answer_region_single`
5. 销售渠道 → `_answer_channel`
6. 具体产品指标（含“空调”或“毛利率 + 产品结构”） → `_answer_product_metric`
7. 产品结构 → `_answer_product_structure`
8. 研发 → `_answer_rd`
9. 营业总收入 / 净利润且跨公司 → `_answer_cross_financial`
10. 单公司财务 → `_answer_financial_single`
11. 其他 → `证据不足`

“具体产品指标”排在“产品结构”之前，避免含“空调”的题面在同时出现
“主要产品”等词时被错误路由到双表收入对比。

## 7. 高风险题专项说明

### Q02：格力“空调收入”

- 目标标签必须是分产品表中的**独立“空调”行**；
- 找不到时输出 `证据不足`，并明确“就本次检索返回的年报页面而言，
  年报未单独披露该业务收入与毛利率，属于披露不足”；
- 其他产品标签只作为候选列出，`是否采信=false`，不得改写成“空调收入”，
  也不得用合并口径替代。

### Q04：苏泊尔两张产品表

- 表 A：`（1） 营业收入构成`，p12/13；
- 表 B：`（2） 占公司营业收入或营业利润 10%以上的行业、产品、地区、销售模式的情况`，p13；
- 输出两组收入、表名、页码、逐项差额和合计差额；
- 状态固定为 `证据冲突`，`确定性作答=false`；
- 正文与审计都写明“差异已发现、原因未明”，不选择其中一组作为正确值，
  也不取平均。

### Q07：小熊 p18 表头

- 数据页 p19，表头来源页 p18；
- 跨页关联状态仍为“算法判定，待人工核验”；
- 线上销售金额、营业收入合计、占比全部 `是否采信=false`；
- 状态为 `需核验`，不因为金额看起来合理就标成已确认。

### Q09：科沃斯 p20 阻断

- 科沃斯 p20 境外收入 `blocked=true`，只能作为候选，`是否采信=false`；
- 科沃斯研发 p24、石头科技研发 p45 与境外 p54 是独立可靠证据，可分别回答；
- 但不得用被阻断的科沃斯境外收入完成“两家公司境外占比对比”；
- 总状态为 `已阻断`，`确定性作答=false`。

### Q10：14 家公司境外收入排名

- 不排序、不计算前三名；
- 只按 `config/companies.csv` 顺序展示每家公司原始指标名、金额、单位、
  占比及占比来源；
- 明确列出三类阻断因素：定义不统一、分母不统一、blocked/待核验/多表差异；
- 审计字段 `排名="未进行"`，并列出 `未提取公司`、`blocked公司`、
  `表头待核验公司`、`同公司多表金额差异`。

## 8. 统计口径

`summarize_answers()` 只输出以下可程序检查的统计：

- **状态分布**：10 题各自的回答状态计数；
- **引用记录数**：所有 `指标` 记录总数；
- **引用完整记录数 / 完整率**：公司、代码、年份、指标原文、数值、单位、
  数据页码、证据原文八项均非空；**不检查数值是否与 PDF 一致**；
- **阻断证据误用数**：`blocked=true` 且 `是否采信=true` 的记录数，应为 0；
- **跨公司混淆数**：指标证券代码不在本题 `检索范围证券代码` 内的记录数，
  应为 0；
- **确定性作答数**：`确定性作答=true` 的题数；
- **答案准确率**：固定为 `未评测`；
- **人工核验状态**：固定为 `未完成`。

引用完整率、页码命中率、检索证据充分率都**不是**答案准确率。本阶段没有
人工逐题核对数值，因此不输出任何准确率数字。

## 10. 仍需人工确认

1. 全部 10 题的数值、单位、公司、年份、指标原文、数据页码和表头来源页，
   仍需人工对照原始 PDF；
2. Q02：确认整份年报是否确实没有独立“空调”分产品披露；
3. Q03：确认题面要求的占比分母是分地区表合计还是营业收入；
4. Q04：确认两张表差异的真实原因，不能预先选定一组；
5. Q05：确认研发投入与研发费用的口径及资本化情况；
6. Q06：确认利润分配预案的审议状态和“每 10 股”口径；
7. Q07：确认 p18 表头与 p19 数据行的对应关系；
8. Q09：确认科沃斯 p20 阻断原因，以及是否存在其他可靠境外收入披露；
9. Q10：统一 14 家公司的海外业务定义和分母后，才可讨论排名；
10. Q01/Q08：复核同比、单位折算和排序的计算过程。
