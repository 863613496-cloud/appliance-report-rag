## 2. 数据来源与合规要求

来源优先级：

1. **巨潮资讯网**（<https://www.cninfo.com.cn>）—— 证监会指定信息披露网站，沪深两市公告齐全，作为主要下载来源；
2. **上交所官网**（<https://www.sse.com.cn>）—— 沪市公司的核验来源；
3. **深交所官网**（<https://www.szse.cn>）—— 深市公司的核验来源。

必须遵守：

- 只能使用 **年度报告全文**，**不得用「年度报告摘要」「业绩快报」替代**（文件名含「摘要」二字的一律排除）；
- 下载后需在 PDF 首页确认标题为「XXXX 股份有限公司 2025 年年度报告」；
- 控制下载频率（`.env` 中 `DOWNLOAD_DELAY_SECONDS`，默认 3 秒），礼貌访问公开服务器；
- 原始 PDF 不入库（见 `.gitignore`），仅在本地保存。

## 4. 快速开始

```bash
# 1) 框架自检（仅依赖标准库，无需安装任何包）
python src/check_setup.py

# 2) 安装第一阶段依赖（下载与解析所需，仅 4 个包）
pip install -r requirements.txt

# 3) 查看界面（可选，需先 pip install streamlit）
streamlit run app.py
```

自检脚本会核对：目录是否齐全、公司数是否为 14、证券代码是否为 6 位字符串、
题目数是否为 10、跨公司题是否≥2 道、`evaluation.csv` 表头是否正确、
`.gitignore` 是否覆盖敏感路径、项目内是否误存真实密钥。

## 5. CSV 字段说明

### 5.1 `config/companies.csv`

| 字段 | 说明 |
|------|------|
| 公司简称 / 证券代码 / 交易所 / 板块 | 公司基本信息；证券代码为**字符串**，注意保留前导零 |
| 报告年份 / 报告类型 | 目标文件：2025 年年度报告 |
| 披露平台 / 核验来源 | 下载来源与官方核验来源 |
| **来源URL** | 年报 PDF 的正式链接，**下载阶段回填**（现为空，未凭空填写） |
| **下载状态** | 待下载 / 下载中 / 已下载 / 下载失败 / 需人工获取 |
| **文件名** | 命名规范：`{证券代码}_{公司简称}_{报告年份}_年度报告.pdf`，如 `000333_美的集团_2025_年度报告.pdf` |
| 下载时间 / 文件字节数 | 下载后回填 |
| **解析状态** | 未开始 / 解析中 / 已解析 / 解析失败 |
| 解析输出文件 / 页码数 | 解析后回填 |
| 备注 | 特殊情况记录（如扫描件需 OCR） |

### 5.2 `config/questions.csv`

10 道固定测试题：**Q01–Q07 单公司题**，**Q08–Q10 跨公司综合题**（满足「至少 2 道」要求）。

| 字段 | 说明 |
|------|------|
| 题目编号 / 题目类型 | Q01…Q10；单公司·财务指标 / 跨公司·同业对比 等 |
| 题目 | 题干原文 |
| 涉及公司 / 证券代码 | 该题需要用到的公司；跨公司题用「；」分隔 |
| 是否跨公司 | 是 / 否 |
| 考察点 | 该题检验的能力（数值抽取、占比计算、跨文档聚合等） |
| 预期出处 | 预期答案所在的年报章节，便于定位核验 |
| 备注 | 口径提醒（如「营业总收入」与「营业收入」的区别） |

> 题库中**不含**参考答案。参考答案属于评测产物，需在年报下载并核对原文后，
> 逐条转录到 `logs/evaluation.csv` 的「参考答案」列——不得提前凭印象填写。

### 5.3 `logs/evaluation.csv`

当前**仅表头、0 行数据**（评测尚未开展）：

```
题目编号,题目,参考答案,实际召回文本块,来源,实际回答,正确性,引用正确性,错误原因,人工备注,测试时间
```

| 字段 | 填写方式与取值 |
|------|---------------|
| 题目编号 / 题目 | 来自 `config/questions.csv` |
| 参考答案 | **人工转录自年报 PDF 原文**，建议同时记录页码 |
| 实际召回文本块 | 检索环节真实召回的文本，须原样粘贴 |
| 来源 | 公司简称 + 报告年份 + 页码 |
| 实际回答 | 系统真实输出的回答，不得润色 |
| 正确性 / 引用正确性 | `正确` / `部分正确` / `错误` / `未评测` |
| 错误原因 | 检索未命中 / 数值抽取错误 / 口径混淆 / 模型臆造 等 |
| 人工备注 / 测试时间 | 复核意见与评测时间 |

## 6. 安全与保密

- `.env.example` 只含**空占位符**，可安全提交；真实密钥写入 `.env`，该文件已被 `.gitignore` 忽略。
- 请勿把 `.env` 内容、API Key、账号密码写入代码、日志、README 或作业报告/截图。
- 财报 PDF、向量索引、运行日志不入库（体积大 / 可能含接口回显内容）。
- 提交前建议运行 `python src/check_setup.py`，其中的密钥扫描会检查项目内是否误存 `sk-` 开头的字符串。
