# 数据来源清单（Data Sources）

本知识库的全部语料来自**巨潮资讯网（cninfo.com.cn，证监会指定信息披露网站）** 披露的上市公司 **2025 年年度报告全文（中文正式版）**，共 **14 家**家电与消费品行业公司。原始 PDF 未纳入本仓库（体积原因），但下方每一条均给出官方全文直链与下载时的校验信息，可逐条复核。

- 检索脚本：`src/download.py --check`（对接 `src/cninfo.py`，调用巨潮公告检索接口）
- 公司清单：`config/companies.csv`（含 `来源URL / 文件字节数 / 页码数 / 下载时间` 字段）
- 机器检索导出：`data_sources.json`
- 检索时间：2026-10-21；下载时间：2026-10-14 ～ 2026-10-16
- 筛选规则：标题含「2025年年度报告」且不含「摘要」「英文」，每家仅保留唯一全文候选；全部候选已逐条标记为「待人工确认」，不存在推测性链接。

## 三、机器检索存的疑点（如实保留）

`src/download.py --check` 对 11 家给出「标题未出现公司名称」提示，主体仅由公告证券代码与检索范围确定。此提示保留在 `data_sources.json` 中，未做人工抹除；下载后以**首页公司全称 + 股票代码 + 报告年度**三要素复核，复核结论记录在 `config/companies.csv` 的 `核验来源` 字段。

## 四、如何复现

```bash
# 1) 只检索候选公告，不下载（约 30 秒，生成 data_sources.json）
PYTHONPATH=. python src/download.py --check --json data_sources.json

# 2) 人工打开上表 URL 核对首页标题后，再执行下载
PYTHONPATH=. python src/download.py --download

# 3) 检查某一家
PYTHONPATH=. python src/download.py --code 000333
```

> 注：`--check` 仅查询公告接口并打印候选，**不下载任何文件、不修改** `config/companies.csv`。
